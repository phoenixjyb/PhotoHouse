# 手机 v65：章节回忆来源测试

版本：65 / `0.65-chapter-memory`。本指南随发布源码准备，OTA 发布结果单独核验。

## 更新后检查

1. 在 **检查更新** 中更新，确认版本为 v65。原有图标应保持一致。
2. 打开一个你有编辑权限的已保存故事，进入一个章节，展开 **管理本章回忆**。
3. 点击 **添加家人回忆来源**。列表显示署名、提交时间和文字／录音类型；这里不展示原文，也不会自动播放录音。
4. 选择一两条已接受且允许处理的家人回忆。若有多页，点击 **更多来源**。已选内容应保留；网络失败时可点击 **重试读取来源**。
5. 点击 **收起选择 · 保留草稿**。在上方点击 **查看家人回忆**，可明确查看所选来源的原始文字或已完成转写；查看不等于保存。
6. 点击 **保存关联**，退出并重新打开故事，确认章节来源仍在。
7. 取消选择一条，再保存并重新打开，确认只移除了章节关联，原始回忆仍在。

## 异常与恢复

- 来源加载失败时，草稿保留，编辑与保存会等待来源重新核验。
- 保存结果不确定时，使用 **重试相同保存**，避免重复提交不同内容。
- 其他人修改了故事而出现版本冲突时，使用重新加载取得最新故事，再确认关联。
- 不具备编辑权限的成员不应看到可执行的章节关联编辑功能。

这次手机界面更新不代表启用自动故事生成。检索澄清的后端更新已经由
PR #48 合入；手机验证与家庭实际体验仍需在安装后完成。
