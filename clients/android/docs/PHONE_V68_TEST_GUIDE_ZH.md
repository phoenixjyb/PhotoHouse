# 手机 v68 候选体验指南：语音失败后如何继续

目标：**68 / `0.68-voice-recovery`**。目前是候选版本，尚未签名或发布。
请等 OTA 实际提供 v68 后再更新，不要卸载应用。范围与证据见
[候选记录](PHONE_V68_CANDIDATE_2026-10-16.md)。

## 正常使用

1. 登录自己的账号，选择有权限的资料库。检查照片、视频、搜索和已保存回忆。
2. 打开拾光助手，明确开始语音会话，说一个日期或人物搜索请求。
3. 检查聆听、处理中、播放的状态是否与实际一致；播放时麦克风应关闭。
4. 点击暂停，检查麦克风关闭；只有点击继续才恢复。点击结束后不能再次录音。
5. 用已有故事试一次“语音继续 → 继续朗读”。每次只读下一段，末段后暂停。

## 若遇到失败

无需故意制造服务故障；出现时记录对应提示和时间即可。

| 情况 | 应看到的说明 | 后续操作 |
| --- | --- | --- |
| 识别失败 | 这段语音未能识别 | 准备好后点继续，再说一次 |
| 请求明确失败 | 这次请求未能完成 | 先查看屏幕提示，再决定继续 |
| 播放失败 | 语音播放未完成 | 可先看文字；继续会返回语音查找 |
| 请求结果不确定 | 保留原有回执核对提示 | 按提示查结果，不自动重复发送 |

暂停时应一直显示“麦克风已关闭”，继续、结束按钮可点击。播放失败后点击
继续，不应重新播放上一段或跳过尚未成功播放的内容。大字体下也应能看清说明
并到达按钮。切换账号、资料库或切到后台时，不应默默开始新的录音。

## 反馈

记录应用版本、时间、语言、所在页面、说出的短指令、提示和是否有声音。
不要发送密码或私人录音。模拟器已检查中英文 150% 字体的六种失败界面；
真实收音、识别、播放、延迟和家人体验仍需实体手机验收。
