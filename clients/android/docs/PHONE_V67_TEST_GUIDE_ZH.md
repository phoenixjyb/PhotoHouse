# 手机 v67 发布后验收：语音继续朗读

目标版本：**67 / `0.67-voice-reading`**。v67 已发布到 phone OTA。请在实体手机上
通过“检查更新”确认实际提供该版本后再安装；不要卸载旧应用。已签名 APK、OTA
完整读回和验收边界见[发布记录](PHONE_V67_RELEASE_2026-10-16.md)。候选准备的历史
记录见[候选记录](PHONE_V67_CANDIDATE_2026-10-16.md)。

## 准备

使用自己有权限的资料库，选择有较长正文、可以分段朗读的已保存回忆或故事。
打开“拾光助手”或故事的私人对话阅读区。先检查照片、视频、搜索和原有回忆
仍可访问。没有就绪内容或服务能力时，记录提示，不要用其他账号的内容代替。

## 一次完整体验

1. 通过助手打开一段已保存正文，点朗读，等待当前段实际播完。
2. 点“语音继续”。首次请求麦克风权限时，先拒绝：不应开始录音或继续朗读。
   重新点“语音继续”并允许权限。应看到正在聆听，且暂停、结束可直接到达。
3. 说“继续朗读”。应只播放下一段，播放时麦克风关闭。不能重复播放上一段，
   也不能新增一条普通聊天回复来代替朗读。
4. 播完后应重新聆听。再说一次“继续朗读”，只进入再下一段。读到最后一段
   后应暂停，麦克风保持关闭。
5. 点击恢复语音后，应回到语音搜索；不能自动接着读旧内容。试问一句普通
   搜索问题，检查能返回结果卡片，而不是继续旧的朗读。

## 停止、权限与中断

- 在聆听阶段分别说“暂停”和“结束”，检查状态与麦克风。口头控制需要先经
  语音识别；播放期间请用可见按钮停止，当前没有边播边听或随时打断能力。
- 在播放中点击暂停或结束。旧音频回调不能让应用再次录音，也不能影响后来
  开始的新会话。
- 在麦克风权限请求期间切换正文或退出阅读，再允许权限：不能启动旧会话。
- 切换账号、资料库，或把应用切到后台再回来：应停止或要求明确恢复，不能
  默默继续录音。网络失败时不能自动重复发送或跳过未成功播放的段落。
- 正文已经被编辑或撤回时，应重新读取当前内容；不能沿用旧段落的位置。
- 把系统字体调大，检查私人阅读区和主助手中的暂停、结束按钮都可到达。

## Web 对照与反馈

配套 API/Web 源码 `88de08e` 已另行部署。现在可以在浏览器用同样正文重复
“语音继续 → 继续朗读 → 暂停/结束”，并把浏览器与手机的观察分开记录。浏览器
与手机的麦克风授权分别处理；不要把页面源码通过或离线合成资格当作真实录音
与播放通过。
