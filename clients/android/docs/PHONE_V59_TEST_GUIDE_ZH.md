# 手机 v59 / Web 候选体验测试

这是下一版的验收清单，**不是已发布说明**。当前已核对的 Windows
手机 OTA 仍为 v58，TV 为 v30；只有部署记录确认发布后再运行新版验收。
本轮源代码的模拟器、浏览器和合成数据检查不能替代真实手机的听感。

## 准备

1. 发布后通过“检查更新”安装 v59，确认版本为 `0.59-saved-section-reading`。
2. 登录自己的账号，选择有已保存故事或回忆录的相册。
3. 使用安静环境和正常音量。先测试文字，再测试语音；不要提供密码或分享
   含家庭内容的完整日志。

## 1. 找回忆与阅读

1. 进入“拾光助手”，输入“找已保存的回忆”，发送。
2. 结果卡片出现后，点击“讲了什么”或“章节”。输入框应填入针对该段回忆的
   完整问题，**点击建议本身不会发送**。检查后再点击发送。
3. 点击“打开已保存的故事”或“打开回忆录”，核对标题和来源；返回助手。
4. 点击“朗读第一章”或“朗读回忆录引言”。这是第一章／引言的分段阅读，
   不是整本书或所有章节自动连播。
5. 准备与播放期间应有“停止”。只有这一段实际播放结束后才出现可用的
   “继续 · 第…段”；每次继续都需要点击。最后一段结束后可以选择重新朗读。
6. 阅读不会自动打开麦克风。停止、切换账号／相册或离开页面后，旧段落不能
   突然继续播放，旧“继续”操作不能作用于另一个故事。

重点记录：开始播放是否等待过久；中文是否清楚；段落边界是否自然；
按钮、停止状态、当前位置在大字体下是否看得清。

## 2. 连续语音与不确定状态

1. 明确点击开始语音，问“找一下照片 28213”（仅当所选相册允许访问该照片）。
2. 看状态依次变化：聆听、识别、处理、准备语音、说话，再回到聆听。
3. 回复播放时不要将它当作可随意插话的全双工通话；本版仍为轮流听／说。
4. 点击“暂停”或“结束”，确认没有继续收音或自动发出新请求。
5. 网络暂时中断时，检查是否清楚提示等待确认。使用“查询结果”恢复已有请求，
   不应自动重发，也不应因恢复而突然开始说话、打开照片或开启麦克风。
6. 完成一个正常语音回合后可展开“上次回合耗时”。这是客户端本次观察到的
   阶段耗时，不是服务器内部性能分析；中断回合不应显示为完整成功。

## 3. Web 键盘与恢复

1. 在中文或英文界面输入多行文字：普通 Enter 换行；Ctrl+Enter（Mac 为
   Cmd+Enter）通过同一个发送动作提交。输入法选字期间不能误发。
2. 单击发送后继续编辑下一条文字。延迟到达的回执不能把焦点从编辑区抢走。
3. 刷新后若有待确认请求，应能看到恢复入口。先滚动或移动焦点，再等加载完成：
   页面不能突然滚回旧消息或改变正在编辑的位置。
4. 结果先出现、能力检查稍后完成时，当前有效卡片的后续问题按钮仍应出现；
   不应需要刷新页面，也不能给旧历史卡片增加可执行动作。

## 4. 预览失败与 TV 源代码后续

手机照片预览失败时，使用显式重试；正常预览不应反复下载。
Web 缩略图失败时应保留标题和可操作的入口，不能留下无法辨认的空白。
TV 本轮新增可见的本页预览重试和遥控焦点恢复，源码预留 v31，尚需单独发布和
投影仪验收；不要将手机 v59 更新视为 TV 已更新。

## 记录结果

只需要记录：设备版本、入口、相册是否有权限、操作步骤、预期与实际、
发生时间，以及必要时的素材编号。区分“没有保存故事／无权限／没有预览／
网络失败／语音质量差”。无需发送原始录音、密码或私人故事全文。

长口述分段录音的内部原型、故事自动生成／润色、标题建议和自动分组，
仍各有单独的启用与质量验收要求；本测试不能证明这些功能已经开放。
