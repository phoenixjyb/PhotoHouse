# 手机 v66 验收：把已核对的 AI 建议带入故事编辑稿

版本：`66 / 0.66-proposal-review`。这是发布候选的测试说明，不代表已经签名、
上架 OTA 或通过实体手机验收。原有应用图标与签名证书必须保留。

## 本次范围

- 可以逐篇选择已生成建议的正文；建议标题单独勾选，默认保留原标题。
- 核对后进入未保存的故事编辑稿，继续修改，再明确确认并保存。
- 原有照片、视频顺序、篇章分组、素材证据、家人回忆关联和署名均保留。
- 待确认问题单独显示，不会当作事实写入正文。

本次不包含另一开发分支尚未合入的 Android 场景检索界面，也不启用服务端模型。
生产环境的故事生成仍有单独的模型质量与启用门槛。如果“整理草稿”不可用，
不要把它当作本次 APK 的故障；取得获准的就绪建议后再做下面的专项验收。

## 更新与基础回归

1. 发布后打开“检查更新”，确认版本号为 v66，再下载安装。无需卸载旧应用。
2. 进入原有资料库，检查照片和视频预览、搜索、故事列表及现有回忆是否正常。
3. 选一份可编辑的故事，检查已经关联的家人回忆与署名仍可查看。
4. 如更新下载失败，记录页面提示与时间。不要发送密码或私人录音。

## 就绪建议专项验收

需要：可编辑的已保存故事、完整且当前有效的篇章回忆关联，以及针对该故事
当前版本生成的就绪建议。不能用过期建议或另一故事的建议代替。

1. 在故事整理或对话建议里，对照现有正文、来源和待确认问题。
2. 默认应没有篇章被选中，建议标题和“我已核对”也未勾选，导入按钮不可用。
3. 选择一篇建议，先保留原标题，勾选核对确认，再导入编辑稿。
4. 检查只替换了所选篇章的正文；其他篇章、标题、图片视频顺序、来源关联和
   家人署名应保持。页面应显示“内容来自 AI 建议”的提示，问题默认收起。
5. 修改正文，确认文字与来源，再点击“保存故事”。重新打开后检查保存结果，
   确认已有家人回忆仍能从对应篇章查看。
6. 用另一份当前建议勾选“同时采用建议标题”，检查修改选择后需要重新勾选
   核对确认。导入后标题仍可手动编辑。
7. 导入后不保存直接关闭，应询问是否放弃；取消放弃后文字保留。没有明确保存
   之前，已保存故事不能改变。

## 失败与权限检查

- 存在未发送的回忆或录音时，先处理这些输入；采用建议不能丢失未发送内容。
- 建议引用的来源未关联到对应篇章时，应拒绝导入。先明确关联符合条件的来源，
  再重新整理与核对，不能把其他篇章的来源自动复制过来。
- 故事版本或建议已经改变时，应拒绝混用旧结果。失败后的“重试此建议”保留
  本次篇章与标题选择；也可以关闭后重新检查最新故事与来源。
- 只读成员不能看到采用建议的控制。切换账号或资料库后，旧页面不能继续操作。
- 把系统文字调大，确认正文、问题、标题、核对选项和保存按钮仍能滚动到达。
