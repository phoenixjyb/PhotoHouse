# 手机 v60 / Web 阅读舒适度测试

这是源代码候选的测试说明，**不是已发布通知**。先确认部署记录，再从
Windows OTA 更新；不要因为看到此说明就认为手机或 Web 已更新。手机候选
版本为 `0.60-reading-comfort`，原图标和签名仍需经过各自的发布核验。

连续语音、助手查找、首章／引言分段朗读和恢复，请继续使用
[v59 清单](PHONE_V59_TEST_GUIDE_ZH.md)。本清单只补充阅读体验。

## 准备

选择自己有权限的相册，准备一个多章节的已保存故事，以及包含两个故事的
回忆录。没有这些内容时，参考[第一则故事指南](../../../docs/FIRST_STORY_GUIDE_ZH.md)
先保存一则合成或自己的故事；不需要上传私人资料给开发者。
建议在系统设置中把字体调大一次，再恢复自己习惯的大小。

## 已保存故事

1. 打开故事，在“阅读字号”选择“较小”“标准”“较大”。
2. 正文应改变大小；标题、按钮和素材来源说明保持原来的大小。系统的大字体
   设置仍应生效，文字和按钮不能挤出屏幕。
3. 选择“较大”，切换本章画面、下一章，再返回。字号应保留，画面和章节应
   只在自己点击导航时改变。
4. 开始手动朗读，再切换字号。字号操作本身不能重新开始朗读、开启麦克风、
   保存文字或发送请求。停止后应保持停止。
5. 关闭故事后重新打开，应回到“标准”。切换账号或相册也不能带入旧的阅读状态。

## 回忆录

1. 打开回忆录并选择“较大”。引言和已打开章节的正文应变大，标题不变。
2. 打开目录并选择另一个章节或子故事。字号应保留，目录所指的故事和正文一致。
3. 浏览长段落，确认可以滚动到全文和素材来源，章节按钮仍容易找到。
   手机底部固定的是章节导航；上一则／下一则故事在可滚动的故事区域中，
   不应再用两整组固定导航挤占正文。
4. Web 上在回忆录整理表单输入一句尚未提交的话，再切换字号。原文字和文体
   选择应保留，不能自动提交或出现新的保存记录。
5. 返回书架再打开，应恢复“标准”；不应突然继续旧故事的声音。

## 预览失败后的恢复

1. 如果故事或回忆录的当前图片显示预览不可用，点击“重试预览”。不必重新打开
   故事；当前章节、字号、正文和尚未提交的补充文字应保留。
2. 检查时按钮应显示忙碌状态；连点不能开始多个读取。网络恢复后图片应恢复，
   失败则仍可重试。正常图片不应显示这个按钮。
3. 在正在检查时切换章节、退出或切换相册。旧图片不能覆盖新章节，也不能触发
   朗读、录音、保存或视频播放。重试不应改变继续阅读的位置。
4. 它只重读派生预览，不会修复服务器缺失文件；持续失败时只报告对应素材编号
   和出现位置，另行安排服务器检查。

## 报告结果

记录应用版本、手机型号或浏览器、系统字号、入口、操作和预期／实际差异即可。
如果文字截断，可以提供不含私人内容的截图；不必发送故事全文或录音。
模拟器和合成浏览器检查只验证界面行为，真实手机的阅读与听感仍需这次试用。
