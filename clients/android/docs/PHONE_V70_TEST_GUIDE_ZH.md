# 手机 v70 发布后试用：导入进度

目标版本：**70 / `0.70-import-status`**。v70 已发布到手机 HTTPS OTA。先在
“设置 → 检查更新”核对版本，再直接更新；无需卸载。签名包和完整下载验证见
[v70 发布记录](PHONE_V70_RELEASE_2026-10-17.md)，候选准备见
[历史候选记录](PHONE_V70_CANDIDATE_2026-10-17.md)。源码和模拟器检查通过；
真实手机上传及家庭可见结果仍待确认。

## 开始前

登录自己的账号，选择有权限的资料库。确认待测试的文件夹中有可上传的照片或
视频。出现错误时，记录提示和大致时间。

## 检查导入进度

1. 打开“添加内容”，点“导入进度”。进入后可点“收起”查看简要状态，再点
   “详情”展开；检查批次及文件列表可以分别展开和收起。
2. 点“检查服务器状态”读取当前历史记录。这个动作不会开始上传，也不表示照片
   预览或视频播放已经准备好。
3. 从系统文件夹选择器选定要测试的文件夹。核对资料库、文件数量和大小；确认后
   才点“开始”。若不打算上传，请放弃本次选择或返回，不要点“开始”。
4. 上传中查看本机已提交进度。暂停后确认进度保留；只有明确点“继续”或“重试”
   才应恢复相应操作。取消的文件不应继续计入字节进度的总量。
5. 上传完成后再点“检查服务器状态”，核对本地队列和服务器记录。刷新失败时，
   不应把旧记录显示成当前可用，也不应自动重新上传。

## 按证据核对状态

| 应用显示 | 可以确认 | 仍需单独核对 |
| --- | --- | --- |
| 已上传，审核状态待确认 | 文件已收到，但审核状态未确认 | 是否已审核、媒体是否可浏览 |
| 等待主人审核 | 服务器记录处于主人审核阶段 | 是否已加入资料库、媒体是否可浏览 |
| 已加入资料库 | 当前可访问资料库中有匹配记录 | 照片缩略图、打开后的照片和视频是否实际可用 |
| 当前不可用 | 当前记录或访问条件不能确认可用 | 不推断具体失败原因，也不访问其他资料库 |

收到文件、审核、加入资料库、预览准备和视频播放是不同阶段。“已上传”或
“已加入资料库”不代表媒体已经可以查看或播放。回到资料库后，分别检查照片缩略
图、打开后的照片和视频播放；若尚未显示或播放失败，记录页面提示和时间，
先检查服务器状态，避免重复上传同一文件。

手机的文件夹选择器、网络、上传、预览、播放和家庭体验验收。
