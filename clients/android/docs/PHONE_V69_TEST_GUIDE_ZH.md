# 手机 v69：文件夹上传复测

适用于已发布的 **v69 / `0.69-upload-recovery`**。
[发布记录](PHONE_V69_RELEASE_2026-10-16.md)包含源码、签名和完整下载验证。
模拟器检查已通过；本指南的真实手机结果仍待确认。

## 1. 更新并选择相册

在“设置 → 检查更新”安装 v69，核对版本。直接更新即可，无需卸载。
登录后进入希望接收照片的资料库，再选择之前失败的秋游文件夹。

## 2. 等待连接验证

从系统文件夹选择器返回后，应用会验证登录和资料库权限。短暂断线会再试一次；
如果仍显示连接错误，点“重试”。同一账号和目标资料库恢复可用后，应进入
“检查上传”，保留本次选择。退出登录、切换账号或资料库权限被撤销时会丢弃选择。

此时不应自动上传。Android 若杀掉整个应用进程，尚未入队的文件夹可能需要重新选择；
已经进入持久队列的中断任务会恢复为暂停，并保留已有进度。

## 3. 核对后开始

检查目标资料库、支持文件数量、总大小和跳过提示。JPEG/PNG 图片每个最多
256 MiB，MP4/MOV 视频每个最多 16 GiB；每批最多 64 GiB，队列最多保留
100 个未完成项目，含之前的任务。不支持、大小未知或超限的选择应显示原因。
没有可上传文件时，“开始”应不可点，“放弃”应可用。

点“开始”。移动数据或网络未知时，先阅读并确认流量提示，再点“开始”。
如果网络在文件夹选择期间发生变化，也应先确认提示，不能静默开始。

## 4. 检查接收和可浏览结果

区分上传接收、审核、后台准备和相册可见这几个阶段。队列接收完成后，等待
预览/视频准备，再重新打开资料库核对。自动审核只适用于主人为该资料库开启的
成员及之后的合格上传；已有记录不会因此自动审核。

如果失败，请提供大致时间、失败阶段和屏幕提示；不必发送密码或私人影像。
已有[语音恢复指南](PHONE_V68_TEST_GUIDE_ZH.md)也适用于本版保留的语音功能。
