# PhotoHouse shared Android mark

The user supplied this artwork and confirmed permission to distribute it under
Apache-2.0. The shared resource `res/drawable-nodpi/photohouse_mark.png` preserves
the supplied PNG bytes unchanged (SHA-256:
`c8fc559e39c5c4d0b9902cafca47e15ac4e6cfa2cbc18d81a40d956e8a8f8909`). This is
the same source SHA-256 used by the web repository.

The adaptive launcher icon uses a white background and an 18dp inset around the
full-color mark. The TV banner places the same mark at its original aspect ratio
on a warm 320 × 180dp background. The fixture, phone and TV applications share
these resources without a library or media dependency between apps.

The supplied artwork has no separate monochrome themed-icon asset. Do not use
the opaque source PNG as a monochrome mask, which would produce a solid square.
