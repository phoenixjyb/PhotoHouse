# Web memoir review context v1

The memoir companion names the current whole memoir below its heading. Opening a
child story through its structure plan keeps this label and the same memoir
conversation. It does not implicitly change the chat target to the child story.
Chinese and English labels follow the panel language; the complete original
memoir title is shown as text and wraps on a narrow screen.

Each whole-memoir proposal chapter also displays its flattened review position
(for example, 24 / 24), independently of the original story's chapter number.
The existing AI review label, source citations, local audio and directory remain
attached to the same chapter. These display fields add no API request, stored
record, generated text, scope expansion or automatic playback.

The UI contract harness checks the full title as text, changed-book revision/title
replacement and the first/last positions of a four-story, 24-chapter fixture. The
protected synthetic browser suite passed 20 checkpoints using the exact locked
CPU environment, including localized context/position labels and inspected
Chinese/English 390px/150-percent layouts. Real services, family accounts and
model output quality remain separate checks.
