# Start a phone story from an album

An existing library album can prepare an ordered selection for a new phone
story. Open **Create a family story → Start from an album / 创建家庭故事 →
从相册开始**, choose an album and review its moments. If moments are already
selected, PhotoHouse asks before replacing them. Cancelling keeps the selection.

## Selection and review

The picker reads the existing protected library album route. It reads ten album
records per page and retains each album's complete ordered list, up to sixty
items. Choosing one rereads its page and compares its identity, revision, order
and theme with the displayed record. A changed or unavailable album leaves the
current selection intact. Refresh the list and choose again.

Before changing the selection, the first twenty-four moments are reauthorized
as supported photos/videos. Selection and theme are then updated together.
Custom and seasonal album themes use the story's everyday theme. Album titles,
descriptions, original memories, bylines, source choices and prose are not
inserted into a story by this shortcut.

For an album with more than twenty-four moments, the first twenty-four start
selected and an explicit notice explains the limit. All remaining album items
remain browsable, eight per page. Remove a selected moment to add a later one.
Returning to the library keeps the chosen order and allows further selection.
If the album reports unavailable media, the picker asks the author to review
the currently accessible cohort.

Creating the outline is a separate button. Preview rechecks the actual selected
media and establishes the story evidence snapshot; it does not save a story.
Source review, chapter arrangement, wording and final save keep their existing
explicit actions. A story contains the reviewed selection; it does not silently
follow later changes to the source album.

## Scope and compatibility

Album pages, selection validation and previews belong to the current protected
account, library and editor generation. Delayed results cannot populate another
editor or clear a replacement account. Album thumbnails have the ordinary
bounded preview budget, and obsolete/cancelled buffers receive best-effort
clearing. Only derived thumbnails are fetched by this picker; originals,
recording, playback and model processing retain separate controls.

The ordinary manual library picker remains available when albums are absent or
the protected album route is unavailable. Anonymous Home and TV do not receive
these album/story credentials or drafts. This client slice adds no server route,
database schema or model installation.
