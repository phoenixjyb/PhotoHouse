# PhotoHouse architecture

## Current source reference

[PhotoHouse architecture, 2026-10-07](./PHOTOHOUSE_ARCHITECTURE_2026-10-07.md) describes the
current source boundaries, data flows, ownership and activation gates. It is a
source architecture map, not a statement that Windows services, models, indexes,
or family devices are available or accepted.

Historical architecture and topic snapshots are not included in this curated
candidate. Their provider inventories, hardware assignments, operational
commands and status require current source or host evidence before use.

The 2026-10-02 open-source candidate is a separate packaging direction. Its
`server/`, `clients/android/`, `models/`, `config/`, `docs/` and `tools/` layout
helps describe distributable source boundaries; it does not establish a public
release or replace private Windows runtime ownership.
