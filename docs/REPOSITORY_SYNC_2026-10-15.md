## 可部署不等于一键安装

纯 CPU 开发、合成测试、源码校验和 API 包准备已有公开工具；家庭配置、密钥、数据库、
媒体、模型权重、签名材料及私有操作回执保存在公开仓库之外。
模型接口与运行位置通过[模型目录](../models/README.md)管理，外部推理实现和权重独立安装。

当前 clean clone 还不能一条命令复制整台家庭服务器。公开、可移植的运行配置生成、
Windows 安装/启动管理、备份/升级/回滚控制器以及端到端安装验收仍是明确维护工作。
现有家庭服务已通过私有固定操作包部署并核验，不能将该证据当作公开安装器已经完成。
具体边界见[运维说明](OPERATIONS.md)。
