# Recent assistant turns

The Web search assistant shows the last eight successful current-page exchanges
with distinct user and assistant labels. Each turn is plain text. A bounded,
keyboard-accessible scroll region keeps the latest reply visible while leaving
focus and page position unchanged. Current result cards and their explicit open
actions retain the existing behavior.

This list clears on refresh, sign-out, account/library changes and pending-turn
recovery. Failed, malformed, uncertain or delayed old-scope responses cannot
enter it. The heading describes the current page; it does not promise deletion
of server records. Assistant troubleshooting records have their own configured
30-day retention, while assistant recordings remain transient.

The visible list is not sent as hidden model history. A later explicit command
uses the existing bounded structured filters and visible IDs. Story and memoir
conversations use their separate persisted history and context contracts. Phone
search already has its own bounded process-memory exchange list.

The synthetic journey verifies the eight-turn bound, literal text rendering,
uncertain/malformed responses, structured context, reload and delayed scope
changes. It checks actual 390 px/150% Chinese and English layouts, bounded
scrolling and keyboard access. No microphone or production provider is used.
Served Web files and family conversation quality remain separate delivery gates.
