# Generated-data story, memoir and restore journey

This check creates a fresh temporary database through the real migrations, draws two geometric JPEG images, and uses the protected API in process. The owner password is generated per run and never printed. All data disappears when the check finishes.

It exercises anonymous access denial, owner and member login, two distinct saved stories, a member's accepted and consented original contribution to each story, explicit story source links, and an ordered memoir. The owner adds clearly labeled synthetic manual opening and transition references, reopens the editorial sidecar, removes one story reference while keeping the original contribution readable, then changes a child story revision and verifies that stale connecting prose is withheld.

The restore leg binds a new external original-deletion journal to the generated
primary, snapshots the database, and withdraws one contribution through the
protected owner API. It closes the first client, restores the older snapshot,
replays the current journal offline, and creates a new `ExistingDatabase`
runtime. Protected HTTP then confirms the generated gallery still opens while
the withdrawn original is absent from both its read endpoint and contribution
list. The JSON result reports `withdrawal_replayed_from_older_snapshot` and
`withdrawn_original_hidden_after_reopen` as true. The data, snapshot and journal
are temporary and removed at exit.

Model generation stays disabled. Network connections, listeners and child
processes are refused; no model, family database or household server is used.

From the root of this source checkout, after its CPU demo dependencies are
available, run the clean setup/restore recipe:

```sh
python -B examples/generated-demo/check_demo.py
```

The generated story narration and memoir prose are demo text supplied by this
check. They are not model output or a quality result. The check validates the
source's migrations, journal replay and protected in-process API; it does not
install or qualify a packaged app, service manager, power-loss durability,
Windows ACL behavior, or a live household restore. See [the journey contract](../../docs/GENERATED_MEMOIR_DEMO.md) for the existing story boundaries and lifecycle.
