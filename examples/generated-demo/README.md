# Generated-data family story and memoir journey

This check creates a fresh temporary database through the real migrations, draws two geometric JPEG images, and uses the protected API in process. The owner password is generated per run and never printed. All data disappears when the check finishes.

It exercises anonymous access denial, owner and member login, two distinct saved stories, a member's accepted and consented original contribution to each story, explicit story source links, and an ordered memoir. The owner adds clearly labeled synthetic manual opening and transition references, reopens the editorial sidecar, removes one story reference while keeping the original contribution readable, then changes a child story revision and verifies that stale connecting prose is withheld. Model generation stays disabled. Network connections, listeners and child processes are refused; no model, family database or household server is used.

After the curated source export and CPU dependency profile are qualified, run:

```sh
python examples/generated-demo/check_demo.py
```

The generated story narration and memoir prose are demo text supplied by this check. They are not model output or a quality result. See [the journey contract](../../docs/GENERATED_MEMOIR_DEMO.md) for the boundaries and lifecycle.
